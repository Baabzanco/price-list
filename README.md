# سیستم مدیریت لیست قیمت - پروتئین گل محمدی

این پروژه یک اپلیکیشن تحت وب حرفه‌ای، مدرن و کاملاً فارسی برای مدیریت و انتشار «لیست قیمت» محصولات گوشتی است.

## ویژگی‌ها
- داشبورد مدیریت و مشاهده آمار
- ویرایش گروهی و سریع قیمت‌ها (بره و دو دندان)
- ذخیره دقیق تاریخچه تغییرات
- تنظیمات پویا (تغییر نام، لوگو، فونت و واحد پول)
- نسخه عمومی برای انتشار لیست قیمت
- خروجی چاپ A4 (Print to PDF) کاملا استاندارد
- طراحی واکنش‌گرا (Responsive) و تم تاریک/روشن مدرن
- بدون نیاز به سرور (محلی با LocalStorage جهت دموی سریع و پایدار)

## پیش‌نیازها
- Node.js > 18
- npm یا yarn

## نصب و اجرا

1. **نصب وابستگی‌ها**
   ```bash
   npm install
   ```

2. **اجرای سرور توسعه**
   ```bash
   npm run dev
   ```

3. **آدرس‌های دسترسی:**
   - صفحه عمومی لیست قیمت: `/price-list`
   - ورود به پنل مدیریت: `/admin/login`
     - نام کاربری: `admin`
     - رمز عبور: `admin`

## Environment Variables
این پروژه برای دمو به صورت Client-Side Database طراحی شده است و نیاز به فایل `.env` برای دیتابیس ندارد.
نمونه فایل مورد نیاز:
```env
# .env.example
APP_URL=http://localhost:3000
```

## بیلد پروژه (Production)
برای بیلد پروژه و تولید فایل‌های استاتیک:
```bash
npm run build
```
سپس می‌توانید پوشه `dist` را در هر وب‌سروری (مانند Nginx، Vercel، Netlify) قرار دهید.

## اطلاعات اولیه (Seed)
سیستم به صورت خودکار در اولین اجرا (در صورتی که دیتابیسی یافت نشود)، دیتابیس را با محصولات اولیه (شامل اقلام گوسفندی، مرغ، گوساله و...) و دسته‌بندی‌های مرتبط پر می‌کند.
